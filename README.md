# AIDV Studios: сайт

Прототип главной страницы aidvstudios.com в палитре «Ночная студия».

## Что внутри
- `index.html`: вся страница в одном файле (стили и скрипты внутри).
- Библиотеки подключаются с CDN: GSAP 3.12.5 + ScrollTrigger, Three.js r128, Lenis 1.0.42, шрифты Unbounded и Manrope (Google Fonts).

## Как посмотреть локально
Откройте `index.html` в браузере. Нужен интернет для CDN и шрифтов.

## Как выложить на GitHub Pages
1. Создайте репозиторий, например `aidv-site`, и загрузите туда содержимое этой папки.
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет по адресу `https://<ваш-логин>.github.io/aidv-site/`.
4. Свой домен aidvstudios.com подключается там же, в поле Custom domain.
